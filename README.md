# suprsend-flutter-sdk

Suprsend SDK for flutter applications

> 📘 v3 version of suprsend_flutter_sdk is available.
>
> We have changed the Flutter SDK authentication from workspace key-secret to public key and JWT based authentication in v3. This is done to improve security in flutter applications.
>
> - For migrating to v3, follow this [guide](https://docs.suprsend.com/v1.2.2/docs/flutter-migration-from-v2)
> - Refer the v3 SDK [documentation](https://docs.suprsend.com/v1.2.2/docs/javascript-sdk)
> - Github [respository](https://github.com/suprsend/suprsend-flutter-sdk) link for v3 version of this sdk.
> - Documentation for this SDK (v2) can be found [here](https://github.com/suprsend/suprsend-flutter-sdk-old/blob/main/docs)
